## Referensi skema lain

- `auth.users` (schema `auth`, owner `supabase_auth_admin`) — tabel user Auth Supabase. Dari perspektif `public`, tidak diberi akses langsung selain via FK & trigger.

## Catatan tipe

- Tidak ada tipe enum/kustom di `public` (periksa `pg_type`+`pg_enum` di `public` = kosong).
- Tidak ada view di `public` (information_schema.views = kosong).
- Tipe `numeric` pada `stock_levels.jumlah` tanpa precision/scale (default `numeric`), sementara `barang.stok` dan `transaksi.jumlah` bertipe `integer`.
- `transaksi.keterangan` satu-satunya kolom nullable di schema inti.
